規則 2：飛行中 0 次 SD 卡寫入 Rule 2: Zero SD Writes During Flight
飛行中 (ARMED) 數據僅寫在記憶體，降落上鎖 (DISARM) 時才一次性寫卡。中途誤觸開關 100% 不死機卡死。 All telemetry is buffered in RAM while ARMED. Writes to SD card ONLY when DISARMED, preventing radio freeze.
規則 3：解鎖飛行中主題鎖定 (ARMED Lockout) Rule 3: ARMED Mid-Flight Theme Lockout
當起飛解鎖 (`ARMED = true`) 時，系統自動鎖定飛行前主題。飛行過程中絕不因手影或光線變化閃爍跳色，杜絕空中視覺干擾！降落上鎖後自動恢復。 Locks active theme while ARMED, preventing mid-air color flashes from shadow changes. Resumes sensing only after DISARMING.
